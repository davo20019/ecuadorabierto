Un solo servidor MCP para todos los módulos de Ecuador Abierto: compras públicas, presupuesto del Gobierno central y el catálogo nacional de datos abiertos.

Conecta por MCP

Agrega un servidor remoto en tu cliente MCP y pega esta dirección: 

https://ecuadorabierto.com/mcp

Transporte: Streamable HTTP · Acceso público · Solo lectura · Sin token ni cuenta. Requiere un cliente con soporte para servidores MCP remotos.

Ejemplo para clientes que aceptan configuración JSON con type: "http": 

{
  "mcpServers": {
    "ecuador-abierto": {
      "type": "http",
      "url": "https://ecuadorabierto.com/mcp"
    }
  }
}

El formato de configuración varía según el cliente. Si tiene una pantalla para añadir servidores remotos, usa directamente la URL.

Compras públicas: seis herramientas

Herramienta Consulta
compras_get_dataset_info Periodo disponible, fecha de actualización, fuente y licencia.
compras_search_entities Busca por query, province y kind. Paginación con limit (1–100) y offset.
compras_get_entity Usa el ruc de una entidad: compras por mes, principales proveedores, adjudicaciones y señales de revisión.
compras_list_provinces Ranking provincial. local_only es verdadero por defecto; falso incluye todas las entidades.
compras_search_processes en vivo Busca procesos en la API OCDS del SERCOP por year, query, buyer o supplier. 10 resultados por page.
compras_get_process en vivo Un proceso por ocid: convocatoria, adjudicaciones, contratos y enlace al registro oficial.

Tipos: municipio, prefectura, parroquia, empresa, otro. Recurso MCP: ecuador-abierto://compras/dataset/info. Cada resultado incluye metadatos y límites de interpretación. Las herramientas de cada módulo llevan su prefijo (compras_, …). Las herramientas en vivo consultan al SERCOP en el momento y fallan con un error claro si su servidor no responde.

Presupuesto: cuatro herramientas

Herramienta Consulta
presupuesto_get_dataset_info Mes de corte, totales nacionales, curva del año, conjunto de datos de origen y licencia.
presupuesto_search_entities Busca instituciones (UDAF) por query y sector. Paginación con limit y offset.
presupuesto_get_entity Usa el code de una institución: grupos de gasto, unidades, principales partidas y avance mensual.
presupuesto_list_groups Totales nacionales por grupo de gasto.

Presupuesto General del Estado: no incluye municipios, prefecturas, juntas parroquiales, IESS ni empresas públicas. Cifras acumuladas en el año hasta el mes de corte. Recurso MCP: ecuador-abierto://presupuesto/dataset/info.

Catálogo de datos: tres herramientas en vivo

Herramienta Consulta
datos_search_datasets Busca en datosabiertos.gob.ec por query y publisher. Paginación con limit (1–50) y offset.
datos_get_dataset Un conjunto por id: descripción, licencia, etiquetas y archivos descargables.
datos_list_publishers Instituciones que publican y cuántos conjuntos tiene cada una.

Devuelve descripciones y enlaces, no los datos. Cada conjunto tiene su propia licencia.

Empieza con una pregunta

“Busca el municipio de Cuenca. Revisa el periodo disponible y resume sus tres principales proveedores, citando la fuente.”

“Compara el monto adjudicado por los gobiernos locales de Azuay y Manabí. Explica qué incluyen esas cifras.”

“¿Qué porcentaje de su presupuesto había gastado el Ministerio de Salud al mes de corte? ¿En qué grupos de gasto va más atrasado?”

“Busca contratos de medicinas de este año en el SERCOP y busca en el catálogo de datos abiertos si hay datos de salud relacionados.”

Antes de interpretar los datos

Las entidades de compras y el presupuesto son instantáneas, no consultas en tiempo real. Consulta los metadatos de cada módulo para saber la cobertura y fecha de procesamiento. Las herramientas en vivo dependen de que el SERCOP y datosabiertos.gob.ec estén disponibles.

No incluye el presupuesto completo, sueldos, pensiones, deuda ni transferencias. Los montos adjudicados no equivalen a pagos ejecutados. La provincia se infiere del RUC y puede reflejar límites históricos o la sede de la entidad. Las señales son motivos de revisión, no pruebas de irregularidad.

No publicamos identificadores de proveedores. Fuente: SERCOP · CC BY 3.0 EC.
